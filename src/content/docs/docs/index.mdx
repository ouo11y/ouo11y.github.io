ouo11y is open-source, OpenTelemetry-native observability for what your users actually experience: sessions, errors, crashes, Web Vitals, traces and session replay from web and mobile apps, joined to your backend traces and shown in Grafana.

Everything is OTLP with OpenTelemetry semantic conventions, stored in Loki, Tempo and Mimir, and runs on infrastructure you control.
