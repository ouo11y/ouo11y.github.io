You build a two-folder shop: an Express API and a React page. First they work with no telemetry at all. Then you start the ouo11y stack from one file, trace the API with the OpenTelemetry Node SDK, add `@ouo11y/browser` to the page, and break things on purpose. At the end, one click in the browser is one trace from the button to the API's own spans, and Grafana shows a **crashed** session with that trace and a replay of what you clicked.

**Time:** about 30 minutes. **You need:** Node 24 or newer, Docker Desktop, VS Code, and about 1.5 GB of disk for the ouo11y images (public, no login).

### Short on time? Run the finished files

<Steps>

1. Download and unzip the finished files above. You get a `tiny-shop/` folder with `backend/` and `frontend/`.

2. Start the stack as on [page 2](/docs/quickstarts/1-tiny-shop/stack/).

3. In `tiny-shop/backend`:

   ```bash
   npm install
   ```

   ```bash
   npm start
   ```

   It prints `[otel] tracing to http://localhost:4318/v1/traces` and serves on `:5001`.

4. In `tiny-shop/frontend`, in a second terminal:

   ```bash
   npm install
   ```

   ```bash
   npm run dev
   ```

5. Open http://localhost:5173, click **Add**, **Checkout**, **Call broken API** and **Throw error**, then go to [page 5](/docs/quickstarts/1-tiny-shop/grafana/).

</Steps>

## What you should see at the end

In Grafana, under **More apps → ouo11y RUM → Sessions**, one session with the status `crashed`. It has the trace of your checkout, from the browser's `POST` span down to `charge card` in the API, and a replay of your clicks.
