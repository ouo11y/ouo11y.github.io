A small shop: an Express API and a React app with five pages. Its page views and three custom events make a funnel: home, a product page, add to cart, checkout, order paid. A script drives 50 real browser sessions through the shop, each one following a persona that stops at a known place. You build the funnel in Grafana, read where shoppers drop and how long each step takes, and open the replay of a session that gave up at checkout.

Plan on about **40 minutes**, most of it waiting for installs and the first image build. You need Node 24 or newer and Docker Desktop.

## The pages

1. [The plain shop](/docs/quickstarts/3-funnels/plain-shop/): an API and a five-page React shop, no telemetry.
2. [The stack](/docs/quickstarts/3-funnels/stack/): collector, Tempo, Loki, rum-api and Grafana, one service at a time.
3. [Instrument](/docs/quickstarts/3-funnels/instrument/): traces from the API, page steps and event steps from the shop.
4. [Fifty shoppers](/docs/quickstarts/3-funnels/shoppers/): the session generator and the answer it prints.
5. [Build and read the funnel](/docs/quickstarts/3-funnels/funnel/): the five steps in Grafana, and what each number means.
6. [Drop-off to replay](/docs/quickstarts/3-funnels/replay/): the sessions that stopped, their replays, clean-up and fixes.
