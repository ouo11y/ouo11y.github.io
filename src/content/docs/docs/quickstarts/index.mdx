Each quickstart starts from an empty folder and ends with something you can see in Grafana. You write every file yourself, one step at a time, and each step says what you should see before you move on. Every file is on the page, and the finished folder is a download, so you never need our repository.

All three use the same small shop: a React page and an Express API. That way the differences are only in what you are learning.

## Which one first?

- **New to ouo11y:** quickstart 1. It is the shortest path to a session you can open.
- **You cannot ship vendor code in your bundle, or want to know exactly what goes over the wire:** quickstart 2. It is the proof that you do not need our SDK.
- **You want product analytics on top of RUM:** quickstart 3, after 1.

## What you need

Node 24 or newer, Docker Desktop, and a terminal. Each quickstart checks your tools in its first step.
