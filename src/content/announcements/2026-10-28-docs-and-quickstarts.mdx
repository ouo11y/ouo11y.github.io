The [docs](/docs/) moved to ouo11y.com and were rewritten for people who have never seen our repository. Every command is copy-paste ready, every file is embedded in the page, and each quickstart offers its finished folder as a download.

## Three quickstarts

| | What you build | What you see at the end |
|---|---|---|
| [1. Tiny Shop](/docs/quickstarts/1-tiny-shop/) | a small Express API and React shop from an empty folder, traced with OpenTelemetry, with `@ouo11y/browser` | one crashed session with its trace and its replay in Grafana; about 30 minutes |
| [2. Without our SDK](/docs/quickstarts/2-tiny-shop-otel/) | the same shop with no ouo11y code in the browser: OpenTelemetry JS, rrweb and web-vitals | the same session, traces and replay, proving the server side needs only OpenTelemetry |
| [3. Funnels](/docs/quickstarts/3-funnels/) | a five-page shop whose page views and custom events make a funnel | fifty generated shoppers, the funnel in Grafana, and the replay of a shopper who gave up |

All three run on the [one-file stack](/docs/start/quickstart/) (collector, Loki, Tempo, Mimir, rum-api, Grafana), which needs pull access to the images during early access.
