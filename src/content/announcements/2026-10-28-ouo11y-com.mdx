ouo11y now has a home at **ouo11y.com**. One rule shaped every page: you can follow it from start to finish, copy every file from the page, and end with what it promised, without opening our repository. The product repository is private during early access; the site is where the instructions live.

## Where to start

| You want to | Start here |
|---|---|
| know what ouo11y is and what it stands for | [Principles](/docs/start/principles/) |
| see it running | [Run the stack](/docs/start/quickstart/): the whole stack from one compose file, and a first session sent with `curl` |
| build a real app and find a crashed session | [Quickstarts](/docs/quickstarts/) |
| instrument your app | [the browser SDK](/docs/instrument/ouo-sdk/), [React Native](/docs/instrument/react-native/), or [your own OpenTelemetry](/docs/instrument/bring-your-own-otel/) |
| run it for a team | [Docker Compose](/docs/operate/compose/), [a single VM](/docs/operate/vm/), [Helm on Kubernetes](/docs/operate/helm/), then [Upgrading](/docs/operate/upgrade/) |
| know what is released and how to upgrade | [Announcements](/announcements/): [current versions](/announcements/#current) and one announcement per release |

[Docs and three quickstarts](/announcements/2026-10-28-docs-and-quickstarts/) says what is in the docs; [the blog](/announcements/2026-10-29-the-blog/) came a day later.

## Early access

The SDKs are public on npm. The container images and the Helm chart stay private until ouo11y reaches a stable version: email [hello@ouo11y.com](mailto:hello@ouo11y.com) with your GitHub user name for pull access. The same address takes questions and corrections to anything on this site.
